Minimal paper release: executable source list
Prepared 2026-10-17

User commands:
  reproduce.py - all 15 manuscript figures and five tables
  get_data.py - verified compact paper-data download
  infer.py - 84 fit definitions; regenerated bundles or optional full input archive
  validate_pipeline.py - optional bounded end-to-end checks

Core scientific code:
  py_code/parameters.py - injected parameters, priors and constants
  py_code/model.py - analytic detector response and noise models
  py_code/triangle_code.py - detector/orbit/TDI sensitivity functions
  py_code/lisa_generate.py - time-domain signal, noise and second-generation TDI
  py_code/sample.py - shared inference imports used by the retained driver modules
  py_code/__init__.py - vendored dependency path

Production data and inference drivers:
  scripts/astro/ch32_astro_formal_20260520.py - eight-parameter astrophysical background
  scripts/astro/ch33_sw10_fullxyz_20260531.py - ten-parameter sound-wave background
  scripts/astro/ch32_precompute_response_noise_tables_20260521.py - full-frequency detector tables
  scripts/astro/xyz4_direct_fullcov_pe_dailyavg_20260506.py - shared daily XYZ detector functions
  scripts/astro/xyz4_multirealization_fullcov.py - ten four-parameter validation realizations
  scripts/astro/ast4_control_diagnostics_20260508.py - four-parameter bundles and fitting

Producers and helpers needed by manuscript appendix plots:
  scripts/astro/run_ast4_covariance_validation_parallel_20260511.py
  scripts/astro/firstday_xyz_simulated_csd_20260512.py
  scripts/astro/plot_ch22_detector_matrix_xyz_compare_20260603.py
  scripts/astro/plot_ch31_xyz_validation_20260520.py

Plotting and deterministic diagnostics:
  paper_cells/cell_NN.py - nineteen necessary cells extracted from result.ipynb
  paper_io.py - explicit numerical input and posterior readers
  diagnostics.py - full-XYZ Fisher/SNR calculations

Dependencies and data:
  vendor/Triangle-Simulator - pinned source and upstream license
  requirements-replay.txt, requirements-inference.txt, constraints-tested.txt
  data/plot_inputs.h5 - numerical figure inputs; no rendered images
  data/cases.json - exact archived result selection and simulation settings
  data/frequency_grid.h5 - exact FFT grid
  data/OrbitData and data/orbit_* - actual orbit inputs
  data/ch32_* and data/ch33_* - selected compact posteriors/nulls and FD tables
  data/ast4_pe_performance_highnlive_20260511 - ten four-parameter posteriors
  data/inference_inputs.h5 - optional 84-fit input collection; not hosted in this release

Each figure-to-script mapping is in reference/figure_code_map.json.
All 84 fit IDs, original result paths, fitted parameters and sampler settings
are in reference/inference_manifest.json. The original full server inventory
is separate from this minimal release.
