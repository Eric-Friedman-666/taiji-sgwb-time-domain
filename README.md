# Taiji SGWB time-domain simulations and inference

Reproduction code for **Full-Covariance Bayesian Inference of Stochastic Gravitational-Wave Backgrounds with Time-Domain Simulations for Taiji-like Missions**, by Qingyuan Liang, Ju Chen, Minghui Du, and Huai-Ke Guo.

The repository contains the time-domain signal/noise and second-generation TDI code, detector response models, full-XYZ likelihoods, parameter-estimation drivers, and plotting scripts used for the paper. The accompanying **54 MB paper-data download reproduces all 15 figures and five numerical tables** from the archived scientific outputs. The expensive PE sampling is a separate, explicitly requested step.

## Reproduce the figures and tables

Python **3.11 or 3.12** is recommended. The clean installation was tested with Python 3.12.7 on macOS; the scripts were also exercised on Linux. Run the following from the repository root:

```bash
git clone https://github.com/Eric-Friedman-666/taiji-sgwb-time-domain.git
cd taiji-sgwb-time-domain
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements-replay.txt
python get_data.py
python reproduce.py all --output outputs
```

`get_data.py` downloads the [versioned paper data](https://github.com/Eric-Friedman-666/taiji-sgwb-time-domain/tree/paper-data-v1.0.0), assembles the archive, verifies its SHA256, and extracts it into `data/`. The numerical data are stored on a separate branch; the download URLs are pinned to the exact data commit. The assembled archive is 56,274,616 bytes (53.7 MiB). If you already have the complete archive, use:

```bash
python get_data.py --archive /path/to/lisa_td_paper_replay_data_20261017.tar.gz
```

The reproduction command verifies **4,502 input and vendored-source checksums**, recalculates the Fisher/SNR diagnostics, obtains posterior summaries from the saved chains, computes the Bayes factors from the full/null evidences, and writes:

- `outputs/figure/`: all 15 manuscript PNG figures, including the appendix figures;
- `outputs/tables/table_1.csv` through `table_5.csv`;
- `outputs/tables/astro_diagnostics.csv` and `fisher_snr_details.json`;
- `outputs/verification.json`: numerical comparisons and the scope of the run.

The default figures use Matplotlib's built-in mathematical fonts. To use LaTeX typography, install `latex` and `dvipng`, then run:

```bash
python reproduce.py all --latex --output outputs_latex
```

`python reproduce.py tables` generates only the tables. `python reproduce.py verify-data` checks the input hashes without generating results.

### Expected verification result

The expected status is **`PASS_WITH_DOCUMENTED_DIFFERENCES`**: 245 of 252 printed table values agree at the printed precision, and seven Table 4 SNR integers differ because the original notebook rescaled previously rounded SNRs. This release calculates the SNRs before rounding and reports the differences explicitly. The Bayes-factor entries agree with the manuscript at their printed precision.

The differences and an optional manuscript correction patch are in [reference/rounding_corrections.json](reference/rounding_corrections.json) and [reference/table4_rounding_correction.patch](reference/table4_rounding_correction.patch). See [the verification notes](docs/verification.md) for the values and tested scope.

## What the data download contains

The compact paper-data archive contains the selected posterior and null-result chains/evidences, the FD detector tables, exact FFT grid, actual orbit DAT files, component-validation matrices, and the numerical mean/percentile/phase statistics used in the detector plots. **It contains no rendered figures.**

It supports deterministic figure/table reproduction. It does **not** contain the optional 5.7 GB collection of every retained observation and detector matrix used by all PE fits. That larger collection is not attached to this release. Fresh inference can instead use input bundles regenerated by the included scientific drivers, as below. No original private server account is needed to use the public code and paper-data archive.

## Rebuild simulations and run PE

Install the additional simulation/inference dependencies:

```bash
python -m pip install -r requirements-inference.txt
python infer.py list
```

The list identifies all 84 paper fits, including the full and null models and the ten four-parameter realizations. [data/cases.json](data/cases.json) contains the science simulation seeds, injected parameters, orbit configuration and cuts; [reference/inference_manifest.json](reference/inference_manifest.json) records the settings and input shapes for each fit.

### Example: regenerate the FD astrophysical benchmark

The static FD detector table needed by this command is part of the compact data download:

```bash
python scripts/astro/ch32_astro_formal_20260520.py build-fd-equal \
  --seed 2026052000 --segments 360 --log-omega-ast -11.5
```

This writes a self-contained input bundle at:

```text
data/ch32_astro_formal_20260520/fd_equal/bundles/fd_equal_fullxyz_r00_seed2026052000_seg360_fmin1em04_fmax0p15_w0p01_ch32_fd_equal_fullxyz_20260520_bundle.h5
```

Set `BUNDLE` to that path and check its likelihood without starting a sampler:

```bash
BUNDLE=data/ch32_astro_formal_20260520/fd_equal/bundles/fd_equal_fullxyz_r00_seed2026052000_seg360_fmin1em04_fmax0p15_w0p01_ch32_fd_equal_fullxyz_20260520_bundle.h5
python infer.py check --case fit_011 --bundle "$BUNDLE"
```

To explicitly launch the full eight-parameter fit or its six-parameter null fit:

```bash
python infer.py run --case fit_011 --bundle "$BUNDLE" --output inference_outputs
python infer.py run --case fit_010 --bundle "$BUNDLE" --output inference_outputs
```

These commands use the corresponding **production sampler settings** from the manifest. They can take substantial time. They are not executed by `reproduce.py` or `get_data.py`.

### TD detector tables and observations

The provided equal-/unequal-arm daily orbit inputs are in `data/orbit_equal_360day/` and `data/orbit_unequal_360day/`. Rebuild the full-frequency response/noise cache before building TD bundles:

```bash
MODE=equal python scripts/astro/ch32_precompute_response_noise_tables_20260521.py
MODE=chunk START_SEG=0 END_SEG=360 python scripts/astro/ch32_precompute_response_noise_tables_20260521.py
MODE=combine python scripts/astro/ch32_precompute_response_noise_tables_20260521.py
```

The two science drivers provide `build-fd-equal`, `build-td-equal`, `build-td-unequal`, `validate-bundle`, and `run-pe` subcommands:

| Driver | Model |
| --- | --- |
| [`ch32_astro_formal_20260520.py`](scripts/astro/ch32_astro_formal_20260520.py) | Instrument noise, DWD foreground, astrophysical background: eight fitted parameters |
| [`ch33_sw10_fullxyz_20260531.py`](scripts/astro/ch33_sw10_fullxyz_20260531.py) | The same components plus a sound-wave background: ten fitted parameters |

For example, the equal-arm TD astrophysical benchmark uses:

```bash
python scripts/astro/ch32_astro_formal_20260520.py build-td-equal \
  --seed 3210481897 --orbit-chunks 360 --log-omega-ast -11.5
```

Choose the exact seed/truth configuration from the manifests for other cases. Use `--help` on the relevant subcommand for the available build options. The TD simulation and detector-cache reconstruction are expensive; they are unnecessary for replaying the supplied figure/table data.

The four-parameter realization generator is [`xyz4_multirealization_fullcov.py`](scripts/astro/xyz4_multirealization_fullcov.py); its portable defaults select ten one-day segments and the original May 6 seed series:

```bash
MODE=generate_one GEN_REALIZATION_INDEX=1 python scripts/astro/xyz4_multirealization_fullcov.py
```

[`ast4_control_diagnostics_20260508.py`](scripts/astro/ast4_control_diagnostics_20260508.py) contains the associated bundle/likelihood code. See [the detailed reproduction notes](docs/reproduction-details.md) for all sampler settings and the optional full-input-archive workflow.

| Files | Purpose |
| --- | --- |
| `py_code/lisa_generate.py` | TD signal/noise generation and second-generation TDI |

| `py_code/parameters.py` | Constants, benchmark parameters and priors |
| `scripts/astro/ch32_*`, `ch33_sw10_*` | Production simulation and inference drivers |
| `paper_cells/cell_*.py` | Nineteen necessary plotting cells extracted from the original notebook |

The [source list](docs/SOURCE_LIST.txt) and [figure-to-code map](reference/figure_code_map.json) provide the complete mapping. The component-validation producers are included because their results appear in the paper's appendix.

## Verification and reproducibility limits

The release was checked by regenerating all 15 figures/five tables, recomputing 84 chain summaries, checking every fit's original truth likelihood, checking the 18 Fisher derivatives, and comparing a full FD simulation and three first-day TD cases with original data. An isolated replay passed with network access and original-project reads blocked.

**The full 84-fit production PE campaign was not rerun for this release.** Nested sampling is stochastic; new posterior and evidence estimates should be compared with their numerical uncertainties. The public wrapper sets and records its sampler seed. Pixel-level figure identity can depend on font/Matplotlib/TeX versions. Details and numerical tolerances are in [docs/verification.md](docs/verification.md).
